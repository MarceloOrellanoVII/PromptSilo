# PromptSilo

> A lightweight, local-first web application to organize, store, combine, and export AI prompts.

PromptSilo eliminates the hassle of keeping prompt snippets, quality tags, camera settings, and lighting styles scattered across text files. It acts as a central vault to construct modular prompt blocks, organize them into structured dataset silos, mix them dynamically, and export complete generation recipes.

---

## Features

* **Modular Prompt Boxes**: Add, reorder, lock, or disable individual prompt blocks to build complex prompt chains.
* **Dataset & Term Packs**: Centralize tags, camera models, lighting setups, and quality boosters into organized datasets for instant retrieval.
* **Wildcards & Randomization**: Insert random entries from dataset silos or roll entire prompt configurations with a single click.
* **PNG Metadata & CSV Support**: Import prompts directly from generated PNG metadata or export prompt history to CSV.
* **Final Prompt Compiler**: Automatically joins enabled boxes using custom delimiters (commas, newlines, etc.) and provides real-time token counts.
* **100% Free & Local**: Runs entirely inside your browser with local storage persistence—no sign-ups, accounts, or external dependencies required.

---

## Quick Start

### Running Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/MarceloOrellanoVII/PromptSilo.git](https://github.com/MarceloOrellanoVII/PromptSilo.git)
   ```
2. Open `promptsilo.html` directly in any modern web browser.

## Keyboard Shortcuts & Controls

| Action | Shortcut / Control |
| :--- | :--- |
| **Randomize Box** | `R` key |
| **Copy Final Prompt** | `C` key |
| **Save Recipe** | `S` key |
| **Toggle Boxes** | Keys `1` through `9` |
| **Undo Action** | `Ctrl + Z` |
